# Commands in Longform

Commands appear in the Obsidian palette with the prefix **Longform:**. The names below are the ones registered by the plugin.

A command that edits the open note is available only while that note belongs to a Longform project. Verse, story, and chronicle commands appear only when the project kind includes that tab. A page-form command appears only when that form is allowed for the kind. A project with no kind keeps every tab and every form.

Right-click a Longform note and open **Insert** (**Inserir**). A **Marks** section there holds **Insert dialogue dash**, **Insert margin note**, **Insert quotes**, and **Insert missing word**. **Insert hyphen** stays in the palette.

## Projects and scenes

| Name | Description |
| --- | --- |
| Open Longform pane | Opens the Longform pane. |
| Open current note’s project | Selects the project of the note you are editing. |
| Jump to project | Matches a project title and shows it in the pane. |
| Jump to scene in current project | Matches a scene in the current project and opens it. |
| Reveal current project in navigation | Shows the project folder in the file explorer. |
| Focus new scene field | Moves to the new-scene field in the Scenes tab. |
| Previous scene | Opens the previous scene. |
| Next scene | Opens the next scene. |
| Previous scene at indent level | Opens the previous scene at the same indentation. |
| Next scene at indent level | Opens the next scene at the same indentation. |
| Indent scene | Indents the current scene one level. |
| Unindent scene | Outdents the current scene one level. |
| Insert multi-scene frontmatter | Writes multi-scene `longform` frontmatter into the note. |
| Insert single-scene frontmatter | Writes single-scene `longform` frontmatter into the note. |
| Delete this project | Asks, then moves that project’s index, scenes, and Longform folders to the system trash. |
| Compile current project with current workflow | Compiles the selected project with its current workflow. |
| Compile project… | Choose a project, draft, and workflow, then compile. |

## Page

| Name | Description |
| --- | --- |
| Hide note properties | Turns that setting on or off. While it is on, the properties block is hidden in editing and reading. The properties stay in the file. |
| Toggle current line highlight | Turns **Highlight current line** on or off. The cursor line is tinted only while the setting is on. |
| Toggle focus mode | Dims every paragraph except the one being written. |
| Toggle typewriter mode | Keeps the cursor line centered. |
| Set page form to prose | Prose. Novel and story, and also chronicle. |
| Set page form to verse | Verse. Poetry. A line break belongs to the poem. |
| Set page form to column | Column. Chronicle. |
| Set page form to script | Script, in a monospace face. |
| New stanza | A blank line and a new verse. Verse form only. |
| Insert scene heading | A scene heading. Script form only. |
| Insert character cue | A character cue. Script form only. |
| Insert parenthetical | A parenthetical. Script form only. |
| Read aloud | Reads the note in the page language. **Off** uses Portuguese. |
| Stop reading | Stops reading aloud. |
| Open beside this page | Opens research, a card, or another draft beside the note. |
| Restore recovered page | Restores the last state if the app closed while you were writing. |

## Marks and private comments

| Name | Description |
| --- | --- |
| Insert dialogue dash | A dialogue dash. |
| Insert margin note | A private margin comment, `%%? … %%`. In the editor the code stays hidden until the cursor is on it, like a link address. It does not enter the output. |
| Insert quotes | Quotes around the selection, or an empty pair with the cursor inside. |
| Insert missing word | A searchable `TK`. |
| Insert hyphen | A compound-word hyphen. Palette only. |
| List margin notes | Gathers the private comments. |
| Show private comments | Shows the private comments. |

## Capture, structure, and plot

| Name | Description |
| --- | --- |
| Capture to inbox | Saves a fragment before it belongs to a book. Works with no project open. |
| Dictate a raw draft | Dictates the scene or the column, in the page language. **Off** uses Portuguese. |
| Stop dictation | Stops dictation. |
| Note from passage | Turns the selection into a card, a revision question, or a fact to check. |
| Read the manuscript through | Joins the manuscript for one continuous reading. |
| Write the contents | Writes the table of contents. |
| New scene with metadata | Creates a scene that already carries its card. |
| New sonnet | Creates a fourteen-line sonnet. |
| New column | Creates a column with a word ceiling. |
| New alternate ending | Hangs another ending on the same trunk. The alternative is a variant and stays out of the manuscript. |

## Bible

| Name | Description |
| --- | --- |
| Open card at cursor | Opens the card for the name under the cursor. |
| Replace a name in the book | Replaces a name in every scene of the project. |

## Verse

These commands belong to a poetry project, or to a project that has no kind.

| Name | Description |
| --- | --- |
| Count syllables on this line | Syllables of the verse at the cursor. The count is Portuguese. |
| Correct verse stress | Stores a stress correction on the word. |
| Look up rhymes by sound | Rhymes by the pronunciation of the page, with a syllable filter. |
| Insert fixed-form scaffold | Sonnet, haiku, villanelle, sestina, redondilha, décima, or quatrain. One line per verse. |

## Story

These commands belong to a novel, a story, or a project that has no kind.

| Name | Description |
| --- | --- |
| Set short-story length | Micro, flash, story, or novelette. The piece has its own floor and ceiling. |
| Pin opening and closing paragraphs | Keeps the first and last paragraphs while the middle is rewritten. |
| Mark what the reader knows | Marks what is already revealed and what is still secret. |
| Set the central effect | One sentence for what the story is for. |
| Edit story motifs | A thread, and where it appears. |
| Estimate reading time for one sitting | How long the whole piece takes to read. |

## Chronicle

These commands belong to a chronicle, or to a project that has no kind.

| Name | Description |
| --- | --- |
| Set column cadence | Weekly, biweekly, or one-off. |
| Set vehicle ceiling | Words, characters, or pages for the paper, the magazine, or the site. |
| Set delivery due date | The due date of this piece, separate from the day’s word goal. |
| Edit column persona | Tone, address, and what the column’s narrator notices. |
| Edit chronicle fact sheet | Date, place, what was seen, and what was invented on top of it. |
| Mark real people to check | Real people to read carefully before sending. |

## Revision

| Name | Description |
| --- | --- |
| Name this version | Names the moment a chapter, a poem, or a column closed. |
| Earlier wording of this paragraph | The previous wording of the paragraph at the cursor. It can be restored. |
| Set revision mark | A mark. What changed after it can be shown. |
| Propose a change | A proposal beside the text. Accept writes it into the manuscript. Refuse keeps the proposal. |
| Read as a reader | A reading without the workshop marks. |

## Habit

| Name | Description |
| --- | --- |
| Start new writing session | Starts a session now. |
| Start a writing sprint | A sprint of the number of minutes you enter. The pane also offers 5, 10, and 25. |
| Stop the writing sprint | Ends the sprint. |
| Set project goal | The book’s goal, separate from the day. Amount, unit, and an optional date. |

## Workshop

| Name | Description |
| --- | --- |
| Open a workshop round | Opens a round. The working manuscript stays editable. The round’s copy does not. |
| Comment on a workshop passage | A comment on a passage. |
| Suggest a workshop change | A suggestion. Accept applies it. Refuse keeps it. |

## Output

| Name | Description |
| --- | --- |
| Edit book opening | Opening pages, dedication, epigraph. |
| Page as it will print | The printed page, including a verse break in a poem. |
| Export as Markdown | Exports Markdown. |
| Export in a format | Exports one of the installed formats. |
| Install publisher and reading workflows | Installs the publisher output and the reading output. |
| Import Markdown folder | Imports a folder of Markdown notes. It creates notes. |
| Import DOCX | Imports a DOCX. It creates notes. |
| Import Scrivener project | Imports a Scrivener project. It creates notes. |

## Life and archive

| Name | Description |
| --- | --- |
| Prepare a submission | A frozen copy of the piece. Sending it does not change the working manuscript. |
| Record a contract | Who, the amount, and when. |
| Build cover and EPUB | Builds the edition beside the manuscript. |
| Back up this project | A copy of the project. |
| Export this project | Takes the files out. The manuscript is not locked to the plugin. |
| Encrypt a copy | An encrypted copy. The open manuscript is not encrypted in place. |
| Decrypt a copy | Decrypts that copy. |
| Add this word to the book | Teaches a word to this book’s dictionary. |
| Count syllables | Portuguese syllables of the selection or the page. |
| Announce this page | A screen-reader pass of the page. |
| Ask about this passage | A question about the passage. The answer does not enter the prose. Suggestions stay off until **Settings → Longform → Suggestions** is on. |
